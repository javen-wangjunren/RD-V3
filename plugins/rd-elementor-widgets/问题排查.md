看了你最新这个 `rd-elementor-widgets.php`，**还没有完全改到最干净的注册方式**。你现在虽然加了 `$widgets_registered` 防重复，但主文件里仍然同时挂了两个注册 hook：legacy 和 modern。

```php
add_action( 'elementor/widgets/widgets_registered', [ self::class, 'register_widgets_legacy' ] );
add_action( 'elementor/widgets/register', [ self::class, 'register_widgets_modern' ] );
```

这不一定会 504，但会让排查变复杂。现在 Elementor 搜不到 `Design Guide`，我建议你先把注册逻辑改到**最小、单一路径**。

---

## 最可能的原因 1：你仍然用了 legacy + modern 双注册

虽然你用了：

```php
private static $widgets_registered = false;
```

但这里还有一个小隐患：你在真正确认注册成功前，就把它设成了 `true`：

```php
self::$widgets_registered = true;
```

如果某次 hook 进来时 `$widgets_manager` 不对、或者注册方法没走成功，后续 modern hook 再进来时会被直接 return，结果就是 **Widget 没注册成功，但系统以为已经注册过了**。

---

## 建议你直接改成这个版本

把 `rd-elementor-widgets.php` 整个替换成下面这个版本：

```php
<?php
/**
 * Plugin Name: RD Elementor Widgets
 * Description: RapidDirect custom Elementor widgets.
 * Version: 0.1.1
 * Author: RapidDirect
 * Text Domain: rd-elementor-widgets
 */

defined( 'ABSPATH' ) || exit;

final class RD_Elementor_Widgets_Plugin {

	const STYLE_HANDLE_DESIGN_GUIDE = 'rd-design-guide';

	public static function init() {
		add_action( 'wp_enqueue_scripts', [ self::class, 'register_assets' ] );
		add_action( 'elementor/frontend/after_register_styles', [ self::class, 'register_assets' ] );

		add_action( 'elementor/elements/categories_registered', [ self::class, 'register_category' ] );
		add_action( 'elementor/widgets/register', [ self::class, 'register_widgets' ] );
	}

	public static function register_assets() {
		wp_register_style(
			self::STYLE_HANDLE_DESIGN_GUIDE,
			plugins_url( 'assets/design-guide.css', __FILE__ ),
			[],
			'0.1.1'
		);
	}

	public static function register_category( $elements_manager ) {
		$elements_manager->add_category(
			'rapiddirect',
			[
				'title' => 'RapidDirect',
				'icon'  => 'fa fa-plug',
			]
		);
	}

	public static function register_widgets( $widgets_manager ) {
		require_once __DIR__ . '/widgets/design-guide-widget.php';

		if ( class_exists( 'RD_Design_Guide_Widget' ) ) {
			$widgets_manager->register( new \RD_Design_Guide_Widget() );
		}
	}
}

add_action( 'plugins_loaded', [ 'RD_Elementor_Widgets_Plugin', 'init' ] );
```

这个版本只保留：

```php
elementor/widgets/register
```

不要再用：

```php
elementor/widgets/widgets_registered
```

## 最可能的原因 2：插件目录结构不对

你的代码里写的是：

```php
require_once __DIR__ . '/widgets/design-guide-widget.php';
```

所以服务器上必须是这个结构：

```text
wp-content/plugins/rd-elementor-widgets/
├── rd-elementor-widgets.php
├── widgets/
│   └── design-guide-widget.php
└── assets/
    └── design-guide.css
```

重点检查两点：

### 1. 主插件文件名是不是正确

必须是：

```text
rd-elementor-widgets.php
```

不要是：

```text
rd-elementor-widgets(1).php
```

你上传给我的文件名是 `rd-elementor-widgets(1).php`，如果你服务器里也是这个名字，虽然插件可以被识别，但后续维护很容易混乱。建议改回标准文件名。

### 2. Widget 文件路径是不是正确

必须是：

```text
/widgets/design-guide-widget.php
```

不是：

```text
/design-guide-widget.php
```

也不是：

```text
/widget/design-guide-widget.php
```

## 最可能的原因 3：Widget 分类没显示

你的 widget 文件里应该有：

```php
public function get_categories() {
	return [ 'rapiddirect' ];
}
```

如果 `rapiddirect` 分类没注册成功，Elementor 里可能不会正常显示这个 widget。

为了测试，你可以先临时改成：

```php
public function get_categories() {
	return [ 'general' ];
}
```

然后去 Elementor 里搜索：

```text
Design Guide
```

如果能搜到，说明问题在自定义分类注册上。
如果还是搜不到，说明 widget 根本没注册成功。

## 最快排查方法

你现在按这个顺序做：

```text
1. 替换 rd-elementor-widgets.php 为上面的简化版
2. 确认目录结构正确
3. 把 get_categories() 临时改成 [ 'general' ]
4. 停用插件，再重新启用
5. Cloudways 重启 PHP-FPM
6. Elementor > Tools > Regenerate CSS & Data
7. 重新打开 Elementor 搜 Design Guide
```

## 判断结论

你现在这个版本的主要问题是：**注册逻辑还是偏复杂，legacy + modern 两套 hook 仍然存在，而且 `$widgets_registered` 可能会提前阻断后续真正注册。**

先用单一 modern hook 版本跑通。跑通后，再慢慢加分类、样式、字段控制。
